Genera un archivo compatible con la opción de importación. Incluye las hojas Productos, Combos y ProductosCombo.

  • Edite precios, disponibilidad, novedades, destacados y ofertas.

  • Vuelva a cargarlo desde Importar catálogo.
Respaldo técnico

Copia completa en JSON

Descarga una copia de seguridad con los datos actuales de productos, combos y sus relaciones.

Este archivo es ideal como respaldo. Para editar y volver a cargar el catálogo, utilice el Excel.

Flujo recomendado

  1. Exporte el catálogo completo en Excel.
  2. Guarde una copia intacta como respaldo.
  3. Actualice únicamente las filas y columnas necesarias.
  4. Regrese a Importar catálogo, valide el archivo y confirme la carga.
